# DeconFlow 1.0.0 RC1

First release candidate of DeconFlow for batch deconvolution of Imaris (.ims) Z-stacks.

## Features

- Gibson–Lanni point-spread function generation and visualization.
- GPU-accelerated Richardson–Lucy deconvolution with non-circulant edge correction and total variation regularization through ImageJ/CLIJ2.
- Interactive XY/YZ previews, linked navigation, crop-based parameter tuning, and adjustable display contrast.
- Batch processing and IMS export, with optional median post-processing with selectable 2D or 3D neighborhoods.

## Downloads

- macOS Apple Silicon (macOS 14+): open the arm64 DMG and drag DeconFlow to Applications.
- macOS Intel (macOS 13+): open the x86_64 DMG and drag DeconFlow to Applications.
- Windows x64 (Windows 10+): run the Setup.exe installer.
- Portable ZIPs and SHA-256 checksums accompany the installers.

Python 3.13, Tk, Java 21, ImageJ/CLIJ2, Bio-Formats, PSF models, and the native IMS writer are bundled. First launch extracts the runtime into the user's application-data folder. No separate Python, Conda, or Fiji installation is required.

## Release candidate limitations

These builds are unsigned and are not notarized. GPU processing requires a working OpenCL driver. Build and launcher checks do not validate GPU compatibility or replace GUI, PSF generation, preview, and IMS export acceptance checks on each target platform. See [platform verification](https://github.com/TomNaber/DeconFlow/blob/codex/stage-1.0.0rc1/docs/platform-verification.md).

This is a prerelease for evaluation before the stable 1.0.0 release.
