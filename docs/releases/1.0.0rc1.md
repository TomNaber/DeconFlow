# 1.0.0 RC1

Self-contained setups for macOS Apple Silicon (14+), macOS Intel (13+), and
Windows x64 (10+). Python 3.13, Tk, Java 21, ImageJ/CLIJ2, Bio-Formats, PSF
models, and the native IMS writer are bundled. No Conda, Fiji, or internet
connection is needed at runtime.

- macOS: open the matching DMG and drag Batch Deconvolution to Applications.
- Windows: run the Setup executable; open the app from the Start menu.
- Portable ZIPs and SHA-256 checksums are also provided.

These builds are unsigned and may require OS approval. GPU processing needs a
working OpenCL driver; install the GPU vendor's driver on Windows. First launch
extracts the bundled runtime into the user's application-data folder.

Apple Silicon GPU processing has been verified locally. Native Intel and Windows
GPU processing still requires hardware acceptance checks; CI build and launcher
checks do not establish GPU compatibility. See docs/platform-verification.md.
